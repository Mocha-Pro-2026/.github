## 🧠 Overview

Mocha Pro is a planar tracking and masking application: it tracks a flat surface through a shot, then uses that data for corner-pin inserts, object removal, rotoscoping and lens correction, either standalone or as a plug-in. It is developed by Boris FX. The product family is positioned as a planar tracking and roto toolset for Windows workflows.

Mocha Pro works as a plug-in suite on Windows 10 and Windows 11 and is installed alongside a host application such as Adobe After Effects.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🎯 Planar Tracking | Tracks a surface by its texture rather than by individual feature points. |
| 📌 Corner-pin Insert | Attaches footage, screens or logos onto the tracked plane. |
| 🧽 Object Removal | Removes tracked objects and rebuilds the background from surrounding frames. |
| ✂️ Rotoscoping Tools | Edge-snapping splines with motion falloff and per-point tracking. |
| 🔭 Lens Module | Estimates and removes lens distortion, including camera calibration. |
| 🧵 Mesh Warp | Deforms the tracked surface with a mesh for non-planar objects. |
| 📤 Track Export | Tracking data is exported to the host as keyframes or a corner-pin effect. |

## Additional Information for Windows Users

Settings created in Mocha Pro are stored in the plug-in's own preset folder, so a reinstall keeps user presets and replaces only program files.

Removing the plug-in goes through the host application's plug-in manager or the Windows uninstall entry, depending on how it was registered.
